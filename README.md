# 취학전 아동 그림어휘력 검사

취학전 아동의 어휘력을 확인하기 위한 정적 웹 검사 도구입니다.

## 구성

- 총 20문항, 4개 범주별 5문항: 음식, 동물, 생활용품, 동작
- 각 문항은 정답 1개와 오답 3개로 구성
- `pic/` 폴더의 SVG 그림을 사용
- 그림 파일을 불러올 수 없을 때는 안내 문구와 예상 그림 파일명만 표시
- 총점, 범주별 점수, 문항별 반응 시간, 전체 평균 반응 시간 제공
- 완료 후 UTF-8 BOM이 포함된 CSV 파일로 내보내기 지원

## 실행

`index.html`을 웹 브라우저에서 열면 됩니다. 로컬 보안 설정으로 SVG가 표시되지 않는 경우, 프로젝트 폴더에서 간단한 정적 웹 서버로 실행하세요.

## 그림 자산

선택한 20개 SVG를 `pic/` 폴더로 복사해 두었습니다. 각 문항 화면과 결과 CSV에 사용한 파일 경로가 표시됩니다.
